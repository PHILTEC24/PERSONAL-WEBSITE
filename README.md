# Personal Website

This repository contains a static personal portfolio website for PHILTEC.

## Structure

- `index.html` - main site page
- `assets/css/main.css` - styles
- `assets/javascript/main.js` - optional script file
- `assets/media/` - images and media assets
- `assets/files/Resume.docx` - downloadable CV

## GitHub Pages deployment

1. Commit and push this repository to GitHub.
2. In GitHub, open `Settings` > `Pages`.
3. Choose branch `main` and folder `/ (root)`.
4. Save and wait for the site to publish.

The site should then be available at:

`https://PHILTEC24.github.io/PERSONAL-WEBSITE/`
